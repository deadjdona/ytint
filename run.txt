# ytint commands

Run these commands from the repository root in PowerShell.

## Validate artifacts and code

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m compileall -q src tests verify.py
.\.venv\Scripts\python.exe verify.py
```

## Run the pipeline

The pipeline expects `data/raw/commentsuite.sqlite3`. Stages read and write the Parquet artifacts configured in `config/settings.yaml`.

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe -m pipeline.runner
```

To rebuild a stage and all downstream stages:

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe -m pipeline.runner --from-stage s02
```

## Launch the dashboard

`src/app.py` is the canonical Streamlit dashboard.

```powershell
.\.venv\Scripts\streamlit.exe run src/app.py
```
