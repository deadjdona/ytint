# ytint commands

Run these commands from the repository root in PowerShell.

## Validate artifacts and code

```powershell
.\.venv\Scripts\python.exe -m pytest -v
.\.venv\Scripts\python.exe -m compileall -q src tests verify.py
.\.venv\Scripts\python.exe verify.py
```

## Run the pipeline

The pipeline expects `data/raw/commentsuite.sqlite3`. Stages read and write the Parquet artifacts configured in `config/settings.yaml`.

```powershell
# Run full 53-stage pipeline sweep
.\.venv\Scripts\python.exe -m pipeline.runner

# Alternatively, via registered console script shortcut:
.\.venv\Scripts\ytint-runner.exe

# High-speed Incremental Delta Runner (processes only new/updated comments, skips in <1s if clean):
.\.venv\Scripts\python.exe -m pipeline.runner --incremental
# Or:
.\.venv\Scripts\ytint-runner.exe --incremental

# Audit difference between SQLite and interim Parquet without running stages:
.\.venv\Scripts\python.exe -m pipeline.runner --diff
# Or:
.\.venv\Scripts\ytint-runner.exe --diff

# Force re-execution of all stages ignoring cache:
.\.venv\Scripts\python.exe -m pipeline.runner --force
```

To execute a single stage:

```powershell
.\.venv\Scripts\python.exe -m pipeline.runner --stage s07
# Or:
.\.venv\Scripts\ytint-runner.exe --stage s07
```

To rebuild from a specific stage onward:

```powershell
.\.venv\Scripts\python.exe -m pipeline.runner --from-stage s02
# Or:
.\.venv\Scripts\ytint-runner.exe --from-stage s02
```

## High-Speed Zero-Copy Analytical SQL Engine (DuckDB)

Execute sub-10ms ANSI SQL queries, multi-table joins, and window functions directly over all 95+ Apache Parquet tables across `data/interim/` and `data/output/`:

```powershell

.\.venv\Scripts\python.exe -m engine.sql_engine --list-tables
# Or via registered console script shortcut:
.\.venv\Scripts\ytint-sql.exe --list-tables

# Describe column types and schema of a specific table:
.\.venv\Scripts\ytint-sql.exe --describe authors
.\.venv\Scripts\ytint-sql.exe --describe comments

# Execute an ad-hoc ANSI SQL query:
.\.venv\Scripts\ytint-sql.exe "SELECT rfm_cohort, count(*) as cnt FROM authors GROUP BY 1 ORDER BY 2 DESC"

# Run a curated analytical preset query:
.\.venv\Scripts\ytint-sql.exe --preset champions_rfm
.\.venv\Scripts\ytint-sql.exe --preset toxicity_outbreaks
.\.venv\Scripts\ytint-sql.exe --preset creator_causal_lift

# Output formatting options (table, JSON, or CSV):
.\.venv\Scripts\ytint-sql.exe "SELECT * FROM comments WHERE toxicity > 0.8 LIMIT 5" --format json

# Export query results directly to CSV or Parquet:
.\.venv\Scripts\ytint-sql.exe "SELECT * FROM authors WHERE monetary > 50" --export scratch/top_authors.csv
.\.venv\Scripts\ytint-sql.exe "SELECT * FROM authors WHERE monetary > 50" --export scratch/top_authors.parquet

# Launch the interactive ANSI SQL REPL studio:
.\.venv\Scripts\ytint-sql.exe --interactive
```
