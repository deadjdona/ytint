# ytint commands

Run these commands from the repository root in PowerShell.

## Validate artifacts and code

```powershell
.\.venv\Scripts\python.exe -m pytest -v
.\.venv\Scripts\python.exe -m compileall -q src tests verify.py
.\.venv\Scripts\python.exe verify.py
```

## Run the pipeline

The pipeline expects `data/raw/commentsuite.sqlite3`. Stages read and write the Parquet artifacts configured in `config/settings.yaml`.

```powershell
# Run full 53-stage pipeline sweep
.\.venv\Scripts\python.exe -m pipeline.runner

# Alternatively, via registered console script shortcut:
.\.venv\Scripts\ytint-runner.exe

# High-speed Incremental Delta Runner (processes only new/updated comments, skips in <1s if clean):
.\.venv\Scripts\python.exe -m pipeline.runner --incremental
# Or:
.\.venv\Scripts\ytint-runner.exe --incremental

# Audit difference between SQLite and interim Parquet without running stages:
.\.venv\Scripts\python.exe -m pipeline.runner --diff
# Or:
.\.venv\Scripts\ytint-runner.exe --diff

# Force re-execution of all stages ignoring cache:
.\.venv\Scripts\python.exe -m pipeline.runner --force
```

To execute a single stage:

```powershell
.\.venv\Scripts\python.exe -m pipeline.runner --stage s07
# Or:
.\.venv\Scripts\ytint-runner.exe --stage s07
```

To rebuild from a specific stage onward:

```powershell
.\.venv\Scripts\python.exe -m pipeline.runner --from-stage s02
# Or:
.\.venv\Scripts\ytint-runner.exe --from-stage s02
```

## Launch the dashboard

`src/app.py` is the canonical Streamlit dashboard entrypoint delegating to `ui.app.main()`.

```powershell
.\.venv\Scripts\python.exe -m streamlit run src/app.py
```

## Generate Executive Intelligence Dossier

Compile a standalone, offline-ready HTML dossier (and print-ready PDF) synthesizing all 53 analytical stages:

```powershell

.\.venv\Scripts\python.exe -m engine.reporter

# Or via registered console script shortcut:
.\.venv\Scripts\ytint-report.exe

# Or automatically during pipeline execution:
.\.venv\Scripts\ytint-runner.exe --report
```

## Ingest Live YouTube Data

Fetch videos, rich metadata, and comment threads directly from the official YouTube Data API v3:

```powershell
# Ingest channel uploads by handle:
.\.venv\Scripts\ytint-ingest.exe --handle '@channel_handle' --max-videos 5 --max-comments 500

# Ingest channel uploads by channel ID:
.\.venv\Scripts\ytint-ingest.exe --channel-id UCxxxxxxxxxxxxxxxxxxxxxx

# Ingest a single video ID:
.\.venv\Scripts\ytint-ingest.exe --video-id dQw4w9WgXcQ

# Offline simulation / testing without an API key:
.\.venv\Scripts\ytint-ingest.exe --mock --handle '@test_demo'
```

```powershell

.\.venv\Scripts\ytint-ai.exe --summary

.\.venv\Scripts\ytint-ai.exe --mock --summary

# Analyze controversy triggers & opposing viewpoints for a comment thread:
.\.venv\Scripts\ytint-ai.exe --thread <ROOT_COMMENT_ID>

# Conversational RAG Q&A ("Ask ytint") grounded in all 53 pipeline metric layers:

.\.venv\Scripts\ytint-ai.exe --provider ollama --model llama3 --summary
```

## Automated Anomaly & Threat Alerting (Webhooks)

Continuously scan forensic and anomaly layers and dispatch notifications to Discord, Slack, Telegram, or generic webhooks:

```powershell
# Run threat scan in dry-run mode (saves JSON digest to data/output/alerts/latest_alert.json):
.\.venv\Scripts\python.exe -m engine.alerting --dry-run
# Or via console script shortcut:
.\.venv\Scripts\ytint-alert.exe --dry-run

# Dispatch to a Discord webhook:
.\.venv\Scripts\ytint-alert.exe --webhook-url "https://discord.com/api/webhooks/..." --severity WARNING

# Dispatch to a Slack webhook:
.\.venv\Scripts\ytint-alert.exe --webhook-url "https://hooks.slack.com/services/..." --severity CRITICAL

# Dispatch to a Telegram bot:
.\.venv\Scripts\ytint-alert.exe --webhook-url "https://api.telegram.org/bot<TOKEN>/sendMessage" --chat-id "<CHAT_ID>"

# Automatically scan and dispatch alerts upon pipeline sweep:
.\.venv\Scripts\ytint-runner.exe --alert
```

.\.venv\Scripts\ytint-replay.exe --video-id WpbN3D5oQBo --export scratch/chronicle.json

Triage viewer comments into high-leverage creator actions (Pin, Heart, Reply Question, De-escalate Crisis), project empirical causal uplift, and draft tone-tailored AI replies:

```powershell

.\.venv\Scripts\ytint-assist.exe --mock --draft-replies --tone warm

.\.venv\Scripts\ytint-assist.exe --video-id WpbN3D5oQBo --export scratch/triage.json
.\.venv\Scripts\ytint-assist.exe --mock --export scratch/triage.csv
```
